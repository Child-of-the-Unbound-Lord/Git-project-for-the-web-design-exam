01 / 先登录

选择一个示例身份

在登录页点击身份卡片可以填入账号，也可以手动输入。先使用管理员完成业务，再退出并用成员身份查看自己的记录。

身份用户名示例密码可以做什么
管理员adminAdmin123!维护耗材、登记出入库、设置下限、核对库存
成员 Amember_aMember123!查看库存、预警和本人领用记录
成员 Bmember_bMember123!查看库存、预警和本人领用记录
这是课程演示数据。 预置账号、耗材数量和流水用于体验功能，不能当作真实问卷回答、管理员意见或真实实验室记录。

02 / 动手走一遍

五分钟演示路线

下面的数字是本次练习的输入与预期结果。请在自己的页面操作后核对，实际结果以保存的记录为准。

  1. 1

    建立一份新耗材

    管理员登录后，在“耗材档案”中新建：编码 DEMO-01，名称“演示连接线”，单位“包”，预警下限 5。保持启用。编码若已存在，换一个未使用的编码。

    检查点：新档案的库存为 0。库存由后续入库形成，不直接填写库存数。

    打开耗材档案
  2. 2

    入库 20 包

    在“入库登记”选择刚创建的耗材，数量填写 20，确认入库。随后到“库存查询”查看它。

    检查点：当前库存为 20，并生成一条入库流水。

    打开入库登记
  3. 3

    为成员 A 领用 15 包

    在“领用登记”选择同一耗材和“成员 A”，数量填写 15。保存后进入“低库存预警”。

    检查点：库存为 5，等于下限 5，因此仍会预警。

    打开领用登记
  4. 4

    补入 2 包，观察预警解除

    新建一笔入库，数量填写 2。刷新库存和预警列表。

    检查点：库存变为 7，已高于下限 5，这份耗材不再出现在预警列表。

    打开低库存预警
  5. 5

    用全部历史核对 7 包库存

    进入“库存核对”，点击“核对全部历史”，找到这份耗材。应看到全部入库 22、全部领用 15、流水净额 7、当前库存 7、差额 0。

    计算过程：20 − 15 + 2 = 7。流水页的日期筛选不会缩小核对范围。

    打开库存核对
  6. 6

    退出，换成员 A 查看

    点击侧栏账号旁的“退出登录”，用 member_a 登录。在“我的领用记录”中找到刚才领用的 15 包。再切换成员 B，这笔成员 A 的记录不应出现。

    检查点：普通成员只查询本人领用；入库、领用登记和库存核对由管理员操作。

    打开流水记录
想多检查一个异常？ 在第 3 步结束、库存还是 5 时，新建领用 6 包的单据。应提示库存不足，库存仍为 5，且不生成成功流水。检查后再做第 4 步。

03 / 看清数据在哪里

浏览器演示与本机服务

工作台会显示当前模式。两种方式使用相同的业务界面，数据保存在不同位置。

对比项当前浏览器演示本机 Python 服务
怎么打开在线工作台，或下载后直接打开离线 HTML下载源码，启动 Python 服务后访问终端显示的地址
数据位置此浏览器、此站点的 IndexedDB此电脑项目目录中的 data/lab.db（SQLite）
账号与权限公开示例账号，模拟管理员和成员的操作差异由服务器检查登录身份和操作权限
能否跨设备共享不能；换浏览器、设备或站点地址不会自动带走数据当前默认只在本机访问，也不会自动云同步
适合用途快速体验页面、讲解流程、准备演示查看和修改代码、运行后台、验证数据库与权限规则

云端共享数据和真实账号是下一轮的优先事项，当前版本尚未提供。不要把在一个浏览器里完成的操作理解为已经同步给另一名组员。

04 / 日常操作

切换账号、保留记录与重置

切换账号

先点“退出登录”，再填入另一个示例账号。退出只结束当前身份，不会删除耗材或流水。需要查看其他标签页新写入的数据时，点击工作台右上角的刷新按钮。

保留自己的操作

浏览器演示依赖当前浏览器存储；清除站点数据可能移除记录。本机版会保留 SQLite 数据库。页面支持导出 CSV，导出范围取决于当前筛选和账号权限。

重置会替换当前数据集。 管理员点击“重置示例数据”并确认后，新增耗材、下限修改和出入库记录会被移除，恢复预置示例。先导出需要保留的记录；CSV 是查看资料，当前版本未提供 CSV 一键恢复。

需要备份本机版时，先关闭 Python 服务，再复制 data/lab.db。在线浏览器演示、离线 HTML 与本机版的存储相互独立，当前没有自动迁移功能。

05 / 遇到问题时

常见问题

离线 HTML 提示无法使用 IndexedDB，怎么办？

当前浏览器可能限制本地文件持久存储。可以尝试支持该能力的浏览器，或下载源码并启动本机 Python 版。页面没有成功保存时，请按提示处理，不要只根据输入框里的内容判断已入账。

查看本机版启动方法

服务器断开后，页面会换成另一套数据吗？

已经建立本机服务模式后，请求失败会提示错误，不会自动切换到浏览器演示数据。确认启动终端仍在运行，再刷新或使用原业务单号重试。

为什么下限设为 0 还有预警？

预警条件是“启用且当前库存小于或等于下限”。因此下限为 0、库存为 0 时仍会提醒。停用耗材不进入预警列表，历史记录仍保留。

重复点击会多扣一次库存吗？

同一业务单号、相同内容再次提交时返回原记录，不再重复入账。同一单号改成不同内容会报冲突。完成一笔后，点击“新建下一笔”再登记新的业务。

核对显示差额，能直接把库存改成一致吗？

核对只显示差异，不会自动改写库存或历史流水。先保留结果，检查输入、记录来源与操作过程，再由两人记录问题和修正方案。

06 / 让课设继续往前走

两人各有一份明确交付

成员 A · 技术整合

负责运行和讲解系统，整合页面、数据接口、出入库与核对逻辑；按实际修改更新报告，并整理演示流程。

成员 B · 需求与测试

负责真实问卷、管理员访谈和规则确认；逐步点击验证页面，记录输入、结果、截图及问题，重点复核预警与权限差异。

AI 已协助准备材料和程序，两人仍需理解自己负责的部分。真实问卷与访谈尚需实际完成；自动化检查结果不能替代调研事实或用户验收意见。
