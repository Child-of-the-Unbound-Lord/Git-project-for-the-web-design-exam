02 / 启动源码版

解压后，运行对应启动脚本

先安装 Python 3.10 或更高版本。当前后台使用 Python 标准库与 SQLite，不需要另外安装第三方 Python 包。

Windows

在解压后的项目文件夹中，双击 start_windows.bat。保留启动终端，按提示打开页面。

也可以在项目目录运行：

py -3 server.py --open

macOS / Linux

在解压后的项目目录打开终端，执行：

bash start_macos_linux.sh

通用启动命令是 python3 server.py --open。

打开终端显示的本机地址。 默认是 http://127.0.0.1:8000。进入“工作台”后使用示例账号登录；运行期间不要关闭终端，结束时按 Ctrl + C。

管理员账号是 admin，密码是 Admin123!。两位成员账号和完整演示步骤见使用指南。本机数据库保存在 data/lab.db；再次启动会保留已有数据。

03 / 了解离线版

离线 HTML 保存到当前浏览器

可以做什么

不用启动 Python，就能体验页面与业务规则。数据保存在当前浏览器中，可演示登记、查询、预警和库存核对。

在线网页、离线文件与本机服务的数据不会自动同步，也没有自动导入彼此数据的功能。

遇到存储限制怎么办

部分浏览器可能不允许本地 HTML 使用 IndexedDB。若页面提示无法持久保存，请使用支持该能力的浏览器，或改用上面的源码启动方式。

需要验证服务器身份检查和数据库事务时，请使用源码版。
