# 程序实现与实测说明

本文件是对《实验室耗材库存与领用管理系统的分析与设计》的程序实现补充。原分析设计报告形成时尚无程序；本次已补充可运行的课程演示版本。真实问卷、管理员访谈和用户验收仍需按实际进度填写。

## 作品组成

一套共享数据的实验室耗材管理作品，包含八个功能页面：耗材档案、入库登记、领用登记、库存查询、出入库流水、低库存预警、库存核对、统计看板。总览提供统一入口。

| 版本 | 数据与权限 | 使用方式 |
| --- | --- | --- |
| 完整本地版 | Python服务端 + SQLite事务；真实会话、角色检查、密码哈希 | 启动Python服务后用浏览器访问 |
| 浏览器演示版 | 当前浏览器IndexedDB；角色用于界面与规则模拟 | 在线演示页或下载包的单文件HTML |

两种模式使用同一套页面和相同业务规则。浏览器演示不承担跨设备共享或真实服务端鉴权；完整本地版用于展示服务端实现。
